# AIPO Feature Scope Draft

## 문서 목적
이 문서는 설계서와 요구사항 정의서를 바탕으로, 백엔드 구현 범위를 기능 단위로 정리한 초안이다.
Codex 또는 개발자가 “무엇을 먼저 만들고, 어떤 책임으로 나눌지” 판단할 수 있도록 한다.

---

## 1. 공통 기능
### 1.1 종목 상세 이동
- 사용자가 종목명 또는 종목 카드를 선택하면 종목 상세 페이지로 이동한다.
- 필수 데이터: 종목 ID
- 선택 데이터: 이전 화면 정보

### 1.2 공통 예외 처리
- 조회 실패, 입력 오류, 데이터 없음 등 예외 상황에서 이해 가능한 메시지를 출력한다.
- 필수 데이터: 오류 상태
- 선택 데이터: 오류 코드

---

## 2. 사용자 기능 범위

### 2.1 사용자 인증
#### 포함 기능
- 로그인
- 로그인 실패 안내
- 회원가입
- 아이디 중복 확인
- 비밀번호 유효성 검사
- 로그아웃
- 회원 탈퇴 요청 / 재확인 / 처리

#### 백엔드 책임
- 사용자 계정 생성
- 비밀번호 검증 및 암호화
- 세션/토큰 발급 및 만료
- 탈퇴 시 삭제 또는 비활성화 정책 처리
- 인증 실패 메시지와 상태코드 일관성 유지

#### 주요 데이터
- 사용자 ID
- 이름
- 아이디
- 비밀번호
- 세션 또는 토큰

---

### 2.2 투자 성향 관리
#### 포함 기능
- 투자 성향 검사
- 투자 성향 스킵
- 투자 성향 재검사

#### 백엔드 책임
- 응답값 기반 성향 산출
- 기본 투자 성향 값 적용
- 기존 결과 갱신
- 매력지수 계산용 사용자 프로필 제공

#### 주요 데이터
- 사용자 ID
- 설문 응답값
- 성향 결과
- 기본 성향 값

---

### 2.3 관심 종목 관리
#### 포함 기능
- 관심 종목 조회
- 관심 종목 삭제
- 관심 종목 순서 정렬
- 알림 우선순위 설정
- 관심 종목 알림 설정
- 상세 화면에서 관심 종목 등록/해제

#### 백엔드 책임
- 사용자별 watchlist CRUD
- 정렬 순서 저장
- 알림 여부 및 우선순위 저장
- 종목 상세와 관심 상태 연동

#### 주요 데이터
- 사용자 ID
- 종목 ID
- 정렬 순서
- 알림 여부
- 우선순위 값

---

### 2.4 공모주 목록
#### 포함 기능
- 공모주 목록 조회
- 공모주 검색
- 공모주 정렬

#### 백엔드 책임

- 사용자 투자 성향에 따른 매력지수 노출 가능성 고려

#### 주요 데이터
- 조회 조건
- 검색어
- 정렬 기준
- 시장 구분
- 종목 ID
- 노출 순위

### 2.5 종목 상세

- 기본 정보 조회
- 매력지수 조회

- 수요예측 결과
- 공모 일정 정보

- 검색어
- 종목 ID

## 3. 관리자 기능 범위

- 집계 쿼리 또는 통계 데이터 조회

#### 백엔드 책임
