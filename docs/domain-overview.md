# AIPO Domain Overview

## 1. 서비스 개요
AIPO는 IPO 예정 기업과 공시문서를 기반으로, 사용자가 기업 정보와 투자 리스크를 쉽게 파악하고 챗봇을 통해 근거 기반 질의응답을 받을 수 있도록 설계된 서비스다.
일반 사용자 서비스와 관리자 서비스, 그리고 AI/RAG 엔진이 함께 동작한다.

## 2. 사용자 역할
### 2.1 일반 사용자
- 회원가입/로그인 후 서비스 이용
- 투자 성향 검사 또는 스킵
- 공모주 목록/상세 탐색
- 관심 종목 관리
- 일정 조회 및 알림 설정
- 챗봇 질의응답 및 기록 관리

### 2.2 관리자
- 서비스 대시보드 조회
- 데이터 수집/크롤링/파이프라인 관리
- RAG 문서 업로드 및 임베딩 관리
- 챗봇 로그와 만족도 통계 관리
- 사용자 관리 및 운영 정책 조정

## 3. 핵심 도메인
### 3.1 Auth / User
- 사용자 회원가입, 로그인, 로그아웃, 탈퇴
- 관리자 로그인/로그아웃
- 사용자 세션 또는 토큰 관리
- 역할 기반 권한 구분(user/admin)

### 3.2 InvestmentProfile
- 투자 성향 검사
- 투자 성향 스킵
- 투자 성향 재검사
- 성향 결과 저장
- 매력지수 계산에 반영되는 사용자 성향 데이터 관리

### 3.3 IPO
- 공모주 목록 조회
- 공모주 검색/정렬
- 인기 공모주 노출
- 종목 상세 정보 조회
- 기본 정보/공모 정보/기업 정보/경쟁률/수요예측 결과 제공

### 3.4 Score / Attractiveness
- 종목 매력지수 계산
- 사용자 투자 성향 반영
- 산정 근거 제공
- 관리자 가중치 조절 반영

### 3.5 Watchlist
- 관심 종목 등록/해제
- 관심 종목 조회/삭제
- 사용자별 관심 종목 정렬 순서
- 관심 종목 기반 알림 설정

### 3.6 Calendar
- 월별 IPO 일정 조회
- 일정 유형 필터
- 날짜별 기업 목록 조회
- 일정 기반 종목 상세 이동
- 관심 종목과 연계된 일정 제공

### 3.7 Chat
- 새 채팅 세션 생성
- 질문 입력 및 답변 조회
- 추천 질문 제공
- 답변 평가
- 채팅 기록 조회/삭제/고정

### 3.8 AdminDashboard
- DAU/WAU 같은 서비스 현황 통계
- 챗봇 만족도 통계
- API 사용량 추이
- 조회 급증 종목 및 관심 종목 Top 10
- 운영 의사결정을 위한 시각화 데이터 제공

### 3.9 DataPipeline
- 외부 공시/증권 데이터 수집
- 크롤링 실행 상태 추적
- 수동 재실행
- 업데이트 주기 설정
- 처리 로그와 실패 상태 관리

### 3.10 RAGDocument
- 신규 공시 PDF 업로드
- 텍스트 추출
- 청크 분할
- 임베딩 생성
- 벡터 DB 저장
- 참고 문서 버전 관리

### 3.11 AI Engine
- 사용자 질문 기반 문서 검색
- 관련 공시 청크 조회
- 근거 기반 답변 생성
- 투자 리스크/지표 분석
- 응답 품질 로깅 및 모니터링

## 4. 저장소 / 데이터 계층
### 4.1 정형 DB
저장 대상 예시:
- 사용자 계정
- 투자 성향 결과
- 공모주 및 기업 메타데이터
- 관심 종목
- 일정 정보
- 채팅 세션/메시지/평가
- 운영 로그 및 통계 데이터

### 4.2 Vector DB
저장 대상 예시:
- 공시문서 청크
- 임베딩 벡터
- 검색용 메타데이터
- 문서 버전 또는 인덱싱 상태

## 5. 외부 연동
- 전자공시 및 증권 데이터 소스
- PDF 파싱 도구
- 임베딩/LLM 서비스
- 관리자 웹/사용자 앱 클라이언트

## 6. 백엔드 관점의 경계
- Auth는 사용자 인증/인가 책임만 가진다.
- IPO는 공모주 조회와 상세 정보 제공을 담당한다.
- Score는 매력지수 계산 책임을 가진다.
- Watchlist와 Calendar는 사용자 개인화 기능을 담당한다.
- Chat은 대화 세션, 질문, 답변, 피드백 흐름을 담당한다.
- Admin은 운영/통계/데이터 품질 관리 기능을 담당한다.
- AI/RAG는 검색과 답변 생성 책임을 가진다.
